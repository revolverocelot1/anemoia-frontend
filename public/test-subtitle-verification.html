🎬 Subtitle Export Verification Test

📹 Manual Testing Instructions

  1. Open the AI Subtitle Editor at http://localhost:5173/subtitle-page-enhanced
  2. Upload a test video (preferably 10-30 seconds, resolution 1080x1920 or similar)
  3. Add some subtitles manually or use auto-transcribe
  4. Export with "Burn subtitles" option - verify in VLC that subtitles are visible
  5. Export with "Add subtitle track" option - verify in VLC under Subtitle > Subtitle Track
  6. Check browser console for test results and any errors

🔍 Expected Results

✅ Burned Subtitles

  • Subtitles permanently visible in video
  • Cannot be turned off in VLC
  • No choppiness (FPS > 25)
  • Works with high resolution (1080x1920)

✅ Embedded Track

  • Subtitle track available in VLC menu
  • Can be toggled on/off
  • Proper timing with video
  • Track labeled as "English"

// After export, check the console for these logs:

console.log(results.summary);

🐛 Common Issues & Solutions

WebCodecs resolution error:
Should be fixed - high res videos are scaled down or use FFmpeg fallback
No loading overlay during transcription:
Should be fixed - TranscriptionLoadingOverlay shows with progress
Choppy preview:
Should be fixed - using requestAnimationFrame instead of setInterval
Embedded subtitles not working:
Should be fixed - FFmpeg service properly embeds VTT tracks
