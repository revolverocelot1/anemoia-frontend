# Sound Effects for Video Editor

This folder contains sound effects for the video editor UI interactions.

## Sound Files Needed:
- `click.mp3` - Button click sound
- `hover.mp3` - Button hover sound (subtle)
- `success.mp3` - Success/completion sound
- `error.mp3` - Error/invalid action sound
- `drag.mp3` - Dragging start sound
- `drop.mp3` - Drop/place sound
- `split.mp3` - Clip split sound
- `delete.mp3` - Delete/remove sound
- `play.mp3` - Playback start sound
- `pause.mp3` - Playback pause sound
- `zoom.mp3` - Zoom in/out sound

## Notes:
- Keep sounds short (< 0.5 seconds)
- Use low volume to avoid being intrusive
- Ensure sounds match the action's nature
- Consider using synthesized/UI sounds rather than realistic sounds

You can use free sound libraries like:
- Freesound.org
- Zapsplat.com
- Or generate them with tools like Audacity or online synthesizers
