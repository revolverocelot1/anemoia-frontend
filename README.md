# SD.Next - OpenXLab Edition

This repository is for testing and deploying SD.Next on OpenXLab.

## Setup

- Clones the `vladmandic/sdnext` repository.
- Copies `config.json`, `ui-config.json`, and `header.py`.
- Launches `webui.sh` with the appropriate flags for OpenXLab.

## Features

- **Backend**: SD.Next
- **UI**: Modern and Standard UIs available
- **Robust Cloning**: Includes fallback for network errors
